- 문제 정의: 과제 명세는 실행 로그(Tool 호출 요청·응답·소요 시간 이벤트)를 로깅 Agent가 세션 단위로 **저장**하고(F3013), 목록·상세 조회(F3014)하며, 제출물에 "대표 요청 1건의 전체 실행 로그 + 재계획 사례" 샘플을 포함하라고 요구한다(과제 요구사항). 명세의 예시 도메인 자체가 KOBIS(영화진흥위원회 오픈API)다. 그런데 KOBIS 이용약관 제6조 제2항은 "회원은 서비스를 통하여 제공받은 결과를 실시간으로 사용하여야 하며, 결과를 복제 또는 저장하거나 제 3자의 서비스로 재 전송할 수 없습니다."라고 정한다(2026-11-18 약관 페이지에서 확인). 제3조 제5항은 출처 명시, 제6조 제5항은 "통합전산망 오픈 API" 이용 명시를 요구한다. NF3007은 "출처와 이용 조건을 기록하고 지켜야 한다"이다. 무엇을 어디까지 저장해도 되는지, 제출 로그 샘플을 어떻게 만들지 정해야 한다.
- 관련 요구사항 ID와 원문 요지:
  - F3012: 메인 Agent가 단계 진입/종료, Tool 호출 요청과 응답·소요 시간, LLM 판단을 이벤트로 발행.
  - F3013: 로깅 Agent가 이벤트를 구독해 세션 단위로 저장. LLM이 요약·가공한 내용으로 원본 이벤트를 대신하지 않고 발생한 사실을 그대로 남긴다.
  - F3014: 실행 로그 목록·상세(순서대로)·삭제, 수정 불가.
  - 과제 요구사항(검증·제출): 검증 결과에 대표 요청 1건의 전체 실행 로그와 재계획 사례 포함.
  - NF3007: 외부 API 출처·이용 조건(호출 한도, 약관) 기록하고 지킬 것.
  - F3015: 계획(영화명·날짜·시각) 저장 — 사용자가 고른 결과물.
