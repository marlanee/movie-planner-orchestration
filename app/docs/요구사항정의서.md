# 요구사항 정의서

영화 관람 플래너는 사용자가 말한 관람 시간에 맞춰 영화 후보를 찾고 선택 근거를 보여 줍니다. 사용자는 실제 상영 시간과 영화관을 확인한 뒤 일정을 저장할 수 있습니다. 대화 화면의 실행 흐름과 세션별 실행 로그로 어떤 조회가 추천에 쓰였는지 확인할 수 있습니다.

## 도메인 선정

시간 조건에 맞는 영화를 추천하려면 후보 목록과 영화별 러닝타임이 필요합니다. 지역을 지정한 사용자가 방문 장소도 확인할 수 있도록 영화관 위치 검색을 붙였습니다. KOBIS의 과거 집계에서 후보를 찾고, 조건을 충족하는 영화가 없을 때 국내 현재 상영작 목록으로 탐색 범위를 넓힙니다.

| 출처 | 사용한 정보와 용도 |
| --- | --- |
| KOBIS | 일별·주간 박스오피스의 제목·순위·영화 코드로 후보를 찾습니다. 영화 코드를 상세 조회에 넘겨 러닝타임·관람등급·장르·개봉일을 확인합니다. 최신 집계가 없는 날짜에는 과거 집계를 사용하고 그 사실을 안내합니다. |
| TMDB | 국내 현재 상영작의 ID·제목·개봉일로 후보를 보충하고, 상세 조회의 러닝타임과 장르를 같은 판단 로직에 적용합니다. |
| 카카오 로컬 | 영화관 이름·주소·지도 링크·전화번호를 검색합니다. 검색 범위는 장소 정보까지이며 실제 상영 여부와 시각은 영화관에서 확인합니다. |
| SSAFY GMS | 사용자 메시지에서 요청 의도와 관람 조건을 추출합니다. 시간 비교와 후보 풀 전환은 코드로 처리합니다. |

## 대표 요청

관람 날짜와 시작 가능 시각을 기준으로 삼습니다. 지역·장르·영화 제목은 선호 조건으로, 종료 시각은 일정 제약으로 사용합니다. 영화별 필요 시간은 러닝타임에 기본 광고 시간 10분을 더해 계산합니다.

| 요청 | 서비스 처리 |
| --- | --- |
| 이번 주 토요일 오후 3시 이후 강남에서 영화 보고 저녁 7시 전에 끝내고 싶어 | KST 기준 토요일을 계산하고 일별 박스오피스 후보의 러닝타임을 조회합니다. 19:00까지 관람할 수 있는 후보와 늦어도 시작할 시각을 계산하고 강남 영화관 위치를 안내합니다. |
| 일요일 오후 2시 이후 대전에서 코미디를 보고 오후 5시까지 끝내고 싶어 | 영화 상세에서 코미디 장르를 확인한 뒤 14:00~17:00 조건을 적용합니다. 첫 풀에서 충족 후보가 없으면 주간 집계와 TMDB 목록을 차례로 탐색합니다. |
| 토요일 오후 3시 이후 시작해서 4시 전에 끝나는 영화 | 60분 구간에서 광고 시간 10분을 뺀 50분을 기준으로 후보를 판단합니다. 재계획을 마쳐도 찾지 못하면 시작 또는 종료 시각의 조정을 묻습니다. |
| 같은 날 3시 이후에 시작해서 4시 35분 전에 끝나는 걸로 | 같은 세션의 날짜와 지역을 이어받고 종료 조건을 16:35로 갱신합니다. 합성 S2에서는 일별 풀을 조회한 뒤 주간 풀로 재계획해 후보를 찾았습니다. |
| 7시 전에 끝나는 영화 추천해 줘 | 새 세션에 시작 가능 시각이 없으면 Tool 호출 전에 되묻습니다. |
| 토요일 3시 이후 마라도에서 영화 보고 7시 전에 끝내고 싶어 | 영화 후보와 지역 영화관을 조회합니다. 카카오가 영화관을 찾지 못해도 영화 판단을 계속하고 위치 조회가 실패한 이유를 알려 줍니다. |
| 어제 박스오피스 순위 알려 줘 | 일별 박스오피스 집계를 조회합니다. |
| 테스트 영화 러닝타임 알려 줘 / 강남 영화관 어디야? | 러닝타임 요청은 일별 집계에서 제목이 일치하는 후보의 상세를 조회합니다. 영화관 위치 요청은 카카오 검색만 호출합니다. |
| 안녕, 이거 어떻게 써? | Tool 호출 없이 관람 날짜·지역·시간대를 알려 달라고 안내합니다. |
